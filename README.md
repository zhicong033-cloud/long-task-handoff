# claude-skills

我自己用的 Claude Skills。每个子目录一个 Skill，`SKILL.md` 就是全部内容。

## Skills

### [long-task-handoff](./long-task-handoff)

长任务对话变长时，写一份交接文档并建议开新会话继续。

LLM 对话每一轮都会把全部历史重发一遍，所以一条会话的总成本大致正比于**轮次的平方**。
在一个真实账户上实测（7,577 次请求）：

| 轮次 | 该轮平均携带的上下文 |
| --- | ---: |
| 第 1–10 轮 | 41,430 |
| 第 11–30 轮 | 72,700 |
| 第 31–100 轮 | 118,458 |
| 第 100 轮以后 | 138,666 |

第 100 轮之后的一次提问，成本是前 10 轮的 **3.3 倍**，而问题本身可能一样简单。

这个 Skill 做三件事：在**任务边界**（不是数到 30 就砍）提议收尾、写一份让重开变便宜的
交接文档、给出新会话的第一条消息。

**它刻意不做的事**：不在你正调一个还没定位的 bug 时打断你，不替你结束会话，
提过一次就不再唠叨。

## 安装

下载 `.skill` 文件后在 Claude 里保存，或者把子目录放进你的 skills 目录。
